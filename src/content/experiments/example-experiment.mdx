Cette première entrée n'est pas une vraie expérience. Elle sert à valider la
chaîne de bout en bout : une carte sur la galerie, une page de détail, un îlot
interactif et les tokens de la charte, le tout sans JavaScript superflu.

## L'îlot, hydraté seulement si on le voit

Le composant ci-dessous est un îlot Preact. Il reste invisible au moteur de
rendu tant que rien ne bouge : le HTML est servi statique, et le JavaScript ne
se charge qu'au moment où l'élément entre dans le champ de vision
(`client:visible`). C'est la règle de la maison : le JavaScript est un budget.

<ExampleDemo client:visible />

La valeur du compteur pilote une variable CSS, qui anime la barre. La logique
vit dans l'îlot, le style vient des tokens partagés, et l'accessibilité (rôle,
libellé, navigation clavier) est traitée dès le départ.

## La suite
